# 弈意 · 棋有呼吸

面向初学者的浏览器围棋游戏。气点、实体连接、跳连与势场始终融入棋盘，无独立教学视图。

## 运行

需要 Python 3；测试需要 Node.js 18 或以上。无运行时第三方依赖，无编译步骤。

```sh
npm start
# 浏览器打开 http://localhost:4173
npm test
```

也可直接运行 `python3 -m http.server 4173 --directory dist`。请通过 HTTP 访问，文件协议不支持模块与棋谱加载。

## 功能

- 9 / 13 / 19 路；同屏双人、基础策略陪练（玩家执黑）。
- 提子、禁入点、全局同形禁止、悔棋、停着；连续两次停着结束。
- 相邻棋子实体桥接；每块棋显示去重后的气数；气点呼吸动画；打吃棋块警示、最后一气菱形标记、指向落点时的合法提子/打吃/自紧气预示、提子淡出。
- 一间跳、二间跳、斜向关系采用不同强度虚连。中间有棋子时抑制跳连；已经实连的棋块不再重复画虚连。斜连两侧断点一侧有敌子时变为暖色受压虚连，两侧均有敌子时消失；斜连从不合并气数。
- 势场基于双方距离核的差值，表现影响强弱，不是地盘判断或胜率。
- 自动本地保存自由对局；SGF 导入 / 导出、主线回放、进度拖动、自动播放。
- 键盘可用方向键在棋盘移动，Enter / 空格落子；支持减少动态效果设置。

## 架构

`dist/engine.js` 是独立规则、SGF 解析与连接识别模块；`dist/app.js` 管理 SVG 渲染及交互；`dist/style.css` 管理响应式布局。使用浏览器标准 API，部署只需要静态文件托管。

基础陪练使用提子收益、气数、邻接、边距等启发式策略，无专业棋力承诺。终局采用子空面积粗计，白贴 7.5；未自动判定死活，应下完争议区域再停着。与采用日本规则的历史棋谱只比较合法着手和最终棋形，不重算其官方胜负。SGF 当前支持 9/13/19 路、第一分支主线、停着、转义属性；带摆子/让子的棋谱会明确拒绝。

## 棋谱来源和许可

原始棋谱保持不变，来自 [Go Game Guru / commented-go-games](https://github.com/gogameguru/commented-go-games)，原评注作者 An Younggil，CC BY-NC-SA 4.0，完整许可在 `dist/games/LICENSE.txt`。这些棋谱限非商业使用；项目代码与棋谱应分别处理许可。

- `cho.sgf`：赵治勋 vs 曹薰铉，2015-07-26，韩国现代围棋 70 周年纪念赛，175 手。
- `gu.sgf`：古力 vs 周睿羊，2015-06-03，第 10 届春兰杯决赛，264 手。
- `lee.sgf`：李世石 vs 陈耀烨，2013-10-08，三星杯，266 手。

视觉理念参考《克苏鲁围棋教学》公开介绍中棋子连接和状态表达的思路，未复制其素材、角色或界面。

规则说明参考英国围棋协会 [How to Play](https://britgo.org/intro/intro2.html)：仅横竖相邻棋子共气，斜向不构成实体连接。
